DESIGN LANGUAGE一艘停在冰川上的星舰

背后有一盏按真实时间走动的灯，管轨迹游标和黑白底片的探照灯显影位置；控件的材质是焊死在空间里的 Windhawk 三色棱镜（1px 环：左上香槟暖金 #FFD89B → 冰晶白 #E6F4FF → 暮光紫，64% 后归零；厚度靠右下 inset -1.5px 的零模糊内暗槽），未选中绝不带玻璃与边，只有选中或鼠标手电靠近时才浮现立体玻璃键帽。这一页每个组件一节，各带一行规矩，每块砖都能按：同组单选、告警点一下算确认、漂移节点点一下停。用这些积木搭成的舰桥在 bridge.html。背景默认是空的，工程面板里切 photo 看底片。

两个文件，一行代码

引入 glacier.css 和 glacier.js，然后 Glacier.init()。画布、太阳、灯、打光、手电、尺寸变化全部自动；给元素加 .gl-brick / .gl-card 就会受光，新塞进来的节点也一样。

一盏灯，两个消费者

overlay 上的轨道游标、root 上黑白底片的探照灯坐标与微弱明度呼吸，用的都是同一个点；底片永远是 100% 黑白银盐灰阶（零色相串味），砖和卡片的材质是 CSS 常数。这一页会动的东西都在听 gl.sun。

砖 · .gl-brick

严禁实心蓝油漆与双层斑马线框：静止态是均匀的烟熏磨砂底（暗槽内全透明）；点亮态肚子保持 80%+ 深邃黑曜石透明感（rgba(18, 22, 32, 0.78)），只留左上 10% 香槟暖金与左下 16% 皇家钴蓝呼吸微光，外加唯一一道 1px 单层光学刀锋（#FFD89B → #E6F4FF → 88% transparent 归零）与右下 inset -1.5px #06080E 硬朗内暗槽。

暗槽 · .gl-track

同一组的几个小开关共用一条下沉的暗槽：比面板暗 3%，不带金边。槽里的砖自己不再要底片，槽就是形状；只有 .on / 悬停的那颗在槽里亮起。

光栅 · .gl-louver

控件是光的传感器，布局就是传感器的摆放。一块砖只能告诉你一个点的光，一排等高、等距的长条才把手电的衰减画出来。长边朝光，节距（条高 + 缝）40–50px，160px 的手电里装得下 3–4 条；缝 8–12px，全页一个值。侧边栏、任务栏、服务列表都是它。

为什么是一排，不是一块

百叶窗上的阳光好看，同一片阳光打在墙上平平无奇。把鼠标在左边这排上下移，远近的条按距离依次亮起又隐去：那是光场被逐级采样出来了。

便当盒是唯一的死法：大小不一的卡片拼在一起，周期全乱，光打上去像一地碎玻璃。

晶格 · .gl-lattice

二维阵列：等大方格、缝 ≤ 6px、圆角 2px。相邻两条 1px 刀锋隔 4px 眼睛分不开，融成一道亮缝，光于是属于缝而不是格子；鼠标停在交叉点亮起的是经线和纬线。圆角跟节距走：独立砖 5–6px，密晶格 0–2px，否则每个交点留一个暗菱形把十字切断。标签（.gl-lattice-label）和空位（.gl-void）不是砖，只占格。

Win10 日历的那枚十字星

Reveal 的封神之作不是按钮，是 7×6 的日期矩阵和计算器键盘：手电罩住 3×3 个格子，经纬两条轴同时从鼠标向外衰减。舰桥右边那块当月日历就是它。

稀疏散落、中心点亮的小方块才是一排瞳孔；密阵列不是。

卡片 · .gl-card

大块冰板：毛玻璃 + 玻璃噪点 + 一圈连续的 1px 归一化渐变环（左上香槟暖金 #FFD89B → 冰晶白 #E6F4FF → 暮光紫，64% 后归零；厚度靠 inset -1.5px 内暗槽），不是两条线。卡片装阵列，嵌套只许一层，里面不许有第三层边。

一张卡片

环用 100% 100% at 0% 0% 椭圆径向渐变按盒子宽高自动归一化：无论方格还是宽条，顶边和左边从 0% 走起，右边和底边落在归零区，不漏紫白斑马线；厚度不在环里，在 inset -1.5px 的零模糊内暗槽里。
