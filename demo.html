GLACIER黑曜石的底，冰的刃

光属于房间，不属于按钮。前景独享 1px 三色空间光谱，底片锁死纯黑白银盐灰阶。搭好的暗座舱在 bridge.html。

01 // .GL-BRICK

冰砖

砖是状态，不是底座。平时保持哑光烟熏，点亮才起 1px 香槟暖金 → 冰晶白 → 暮光紫 归一化刀锋与 #06080E 右下沉降槽。

02 // .GL-TRACK

暗槽

同组开关共用一条 #050A18 下沉暗轨，待机项背景全透明，槽里只亮 选中那一颗 立体玻璃键帽。

03 // .GL-LOUVER

光栅

一维等高长条阵列（节距 48px），长边朝光，把 160px 手电与 240px 太阳的径向衰减 一格格采样出来。

04 // .GL-LATTICE

晶格

密排方格圆角压到 2px，相邻两条 1px 刀锋隔 4px 融成亮缝——鼠标停在交点，亮起的是 经纬十字星。

05 // .GL-CARD

冰板

大块黑曜石毛玻璃 + 分形噪点 + 1px 连续渐变环。容器嵌套 只许一层，内部绝不叠第三道边框。

单层容器

大块面板收纳阵列与长文，内部保持 80% 黑曜石透光率，靠 inset -1.5px 交代厚度。

内嵌光栅

06 // .GL-ICON

图标

通过 .gl-icon 把高饱和度 emoji 与位图压成冷石板银灰，绝不抢走 刀锋与告警 的色温预算。

07 // .GL-PROSE

蚀刻长文

三轨字体栈（--gl-font-display / --gl-font-sans / --gl-font-mono）。正文压在 #8E9BAE 冷灰，层级靠 明度与色温阶跃 拉开，不靠粗笨黑体。

光学蚀刻：为什么暗座舱不能用纯白排正文

在 #13141c 的极暗深空基底与黑曜石毛玻璃上，文字不是印在纸上的黑墨水，而是刻在晶体表面被微光点亮的光学蚀刻（Laser Etching）。如果直接用纯白排满整篇段落，视网膜上的光渗效应会让亮字在暗底上刺眼眩目。

「把全部色相预算留给前景的 1px 棱镜刀锋，把全部明度阶跃留给真正携带信息熵的破局词。」——卡西尼号银盐底片显影守则

三轨字体栈与信息熵梯度

常规叙述段落压在 #8E9BAE（62% 冷石板银灰），行高拉开到 1.8；当句子里出现高信息熵的核心判断时，用冰晶白 500 字重微光提亮或 香槟暖金锚点游丝 让概念自己从灰阶段落里浮出来。

08 // .GL-SLIDER

刀锋滑块

#060911 下沉暗槽只擦亮 1px 迎光底唇，游标是一枚向外凸起的 黑曜石键帽，拖拽时手电实时锁死游标中心。

09 // .GL-INPUT

暗槽输入

砖向外凸，输入框向内沉。左上压 #03050B 崖壁暗影，待机字压在 #8E9BAE 冷灰，聚焦才提亮为 #DCE8FF 冰白并点亮底部 1px 暖金光谱底刃。
